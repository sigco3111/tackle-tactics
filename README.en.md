# Tackle Tactics

A turn-based positioning game in a football kit: 22 players act one at a time, fastest first, on a 50 × 30 grid.
Make space, deny space, beat the clock. Play a match (vs AI, hotseat, AI vs AI) or a career up a 5 × 10 league
pyramid with training, multiclassing, transfers, injuries, aging, stories and match prep. Design notes:
[`concept.md`](concept.md).

Web app (Vite, TypeScript, [Nørd](https://www.npmjs.com/package/@grainular/nord)) with a [Tauri 2](https://tauri.app)
desktop shell. The whole UI renders onto a fixed **1600×900 stage** scaled to the window (`src/ui/stage.ts`), so
screens are laid out once like a game; only long lists scroll inside their own panels.

> [!NOTE]
> **This game is vibe-coded.** It's a hobby project built by directing AI coding assistants (Claude Opus 5.5 via
> Claude Code, and GPT 6.2 Sol) rather than writing every line by hand. The design, the decisions and the
> playtesting are human; much of the code is not. Expect rough edges, odd balance and the occasional bug, and treat
> the code accordingly before reusing it.

## Building the game

The code is in this repository; the **art and music are not**. The art comes from a licensed asset pack whose
license allows using it in games but not sharing the files on their own, so it must never be committed (a public
repo would hand the pack out). Both `assets/` and the generated `public/assets/` are git-ignored.

**Requirements:** Node 22+ (see `.nvmrc`); for the desktop app also a Rust toolchain (`rustup`).

**1. Get the art pack.** Buy or download _Soccer Match - Top Down Football Tileset & Players [32x32]_ by bubbabba
([bubbabba.itch.io](https://bubbabba.itch.io)) and unzip it into `assets/`, so this folder exists:

```text
assets/
├── Soccer_Match_-_Top_Down_Football_Tileset_&_Players_[32x32]/
│   ├── 64/            ← the game uses the 64 px art
│   └── license.txt
└── music/             ← optional: songs for the in-game radio
```

**2. Install and run.**

```bash
npm install
npm run dev              # http://localhost:5173
npm run desktop          # or the desktop app (Tauri)
```

`dev` and `build` first run `scripts/ensure-assets.sh`: if `public/assets` is missing it copies the art the game
uses out of the pack (`scripts/copy-assets.sh`, about 6 MB of the pack's 50+), and if the pack isn't there either it
stops with these instructions. After updating the pack, run `npm run assets` to copy it again.

**3. Music (optional).** Drop audio files into `assets/music/` (see [Radio](#radio)). Without them the radio simply
doesn't appear.

**4. Release builds.** `npm run web:build` (browser, a zip for itch.io) or `npm run desktop:build` (macOS + Windows, into
`releases/<version>/`, see [Releases](#releases)). The art and songs are bundled into the build, which the license
allows: it's the game, not the pack.

## Radio

Every audio file in `assets/music/` becomes a song on the in-game radio (`scripts/music-plugin.ts`, read at dev and
build time). Name files `Artist - Title.ext` (or just `Title.ext`); an optional leading number (`01 `) sets the
order, and the first song opens the station while the rest shuffle. WAV/AIFF are converted to AAC once (cached in
`node_modules/.cache/tt-music`); MP3/M4A/OGG are used as-is. The title screen has a floating player, the career header
has playback controls, and the match toolbar has a Music button. **N** skips to the next song and **R** toggles the radio.
Settings → Sound has volume, the in-match level and per-song switches.

**Your own songs.** Players can add music to the station without rebuilding anything: the desktop app plays every
audio file in a `Tackle Tactics` folder in the system Music folder (`~/Music/Tackle Tactics`, `Music\Tackle Tactics` on
Windows), created on first launch; Settings → Sound has **Open music folder** and **Rescan**. The browser build has
**Add songs…** instead, keeping the files in the browser's storage. Songs are named like the station's ("Artist -
Title"); MP3 and M4A play everywhere, other formats depend on the platform. See `src/ui/myMusic.ts` and the
`*_music*` / `read_song` commands in `src-tauri/src/lib.rs`.

- `src/ai/brain.ts`: the heuristic AI (formation slot + role job, risk-weighted kicks, team styles, game state,

- `src/sim.ts`: headless AI-vs-AI runner used by the tests and tuning harnesses.
- `src/world/`: procedural players, clubs and stadiums.
- `src/meta/`: the career (`career.ts`), player value and growth (`player.ts`), stories, letters and quests
  (`story.ts`), match prep (`prep.ts`) and the save slot (`storage.ts`).
- `src/ui/`: App routing, the match view and controller, the hub, settings, tutorial, radio, audio, commentary,
  sprites (with runtime palette swaps) and stadium rendering; `styles.css`, `fonts.css`, generated `frames.css`.
- `src-tauri/`: the desktop shell (window fitting, save-file commands).
- `scripts/`: asset copy, frame generator, the music Vite plugin.
- `test/`: engine, abilities, set pieces, bonus turns, career, and stories tests (the save-file tests are Rust, in
  `src-tauri/src/lib.rs`).

## Rules as implemented

- **Round** = all 22 act once, sorted by Speed, teams alternating. That is the concept's "turn counter" (default 30).
- A player's turn: **move** (or hold), then, if relevant, **act**: carrier passes/shoots/keeps; a defender next to the carrier may tackle.
- **Marking**: off-ball runs stop on entering an opponent's adjacent cell. The carrier may dribble through, but each one is a tackle reaction.
- **Reactions**: one per player per round, refreshed at the start of their own turn. Tackle when the carrier moves next to you, intercept when the ball passes next to you, keeper save on shots. A failed reaction leaves you _staggered_ (no reaction until your next turn).
- **Kicks**: aim anywhere. The orange disc is where it may land; it grows with distance and shrinks with skill. Passes over `loftThreshold` cells are lofted and can only be cut out near take-off/landing. Aim at the goal mouth to shoot.
- Timer expiry loses the action (or let the AI play it: setting).
- **Tackles are duels; the winner gets an extra turn** right away (`match.tackleBonusTurn`). Take the ball and the tackler goes again; miss a deliberate tackle or slide and the _carrier_ gets it, to escape (`missedTackleBonus`; reaction tackles during a dribble only reward the winner of the ball). The extra turn is for getting clear: move and pass, no shot (`tackleBonusMode`). A foul cancels it. The AI weighs the risk of a miss (`ai.missRisk`).

## Team styles, fatigue & substitutions

- **Styles** (`ai.styles`): Balanced, High press, Low block, Direct, Possession. Additive tweaks to the AI knobs; a club's style is stable (`styleOf`, from its id). Late in a match teams **protect** a lead or **chase** a deficit (`ai.protect` / `ai.chase`).
- **Fatigue** (`fatigue`): running, bursts and tackles drain stamina; below 50 a player loses a move point, below 25 two plus slower reactions. Older players tire faster. Rates scale with match length.
- **Subs** (`subs`): 3 per match from a 5-player bench (quick matches generate one; careers use the best fit non-starters). Press **B** for the bench. Keepers only swap with keepers. The AI subs tired players from half time, tilted by the scoreline.

## Tutorial & match prep

- **Tutorial** (title screen): eight staged lessons on a real board (`src/ui/tutorial.ts`): move, pass, dribble past reactions, tackle, shoot, abilities, a corner, how a round flows.
- **Match prep** (career, opens from the next-fixture button): scouting (style, form, position, threats), the referee and conditions, your **game plan** (drives your auto-managed players; a plan that counters theirs is a morale edge on the day: press > possession > deep > direct > press) and a **team talk**.
- **Stories** (`src/meta/story.ts`): a rival club and derbies, benched players asking for minutes (promises are remembered), losing-streak and low-morale letters, veterans, and follow-ups to earlier choices.

## Set pieces & the referee

- **Corners** come from parries tipped round the post, blocked shots, headed clearances, deflected wide shots and balls flicked out over the byline.
- **Free kicks in the final third** (`setPieces.freeKickForward`) get the same treatment; elsewhere a foul is a plain free kick (no moving, nobody may tackle, the wall stands 2 cells back).
- **Setup:** both sides arrange themselves automatically, then alternate up to `setPieces.placements` moves each (attackers first) inside the box plus `zoneMargin`. Click a player, then a cell; Space when happy.
- **The kick:** the taker gets the next turn out of order. A ball aimed into the box is a lofted delivery attacked with headers (defenders get a small goal-side edge, composure helps). Free kicks can also be shot.
- **No offside**, on purpose: turns are sequential, so a line would feel random.
- **Referees** are drawn per match. Style (Lenient / Fair / Card-happy) is fixed per name, so officials keep their reputation across a career. Style sets how often missed or won challenges are fouls, card and straight-red chances (slides are riskier), and how often advantage is played. See `config.referee`.

## Abilities (DnD model)

Players have **class levels**; multiclassing is just level distribution (e.g. `MF 6 / ST 3`). An ability unlocks
when the level _in its class_ reaches its `unlock`. All numbers live in `config.abilities` / `config.passives`.

| Class      | Ability (unlock)                  | Phase    | What it does                                                                                          |
| ---------- | --------------------------------- | -------- | ----------------------------------------------------------------------------------------------------- |
| Winger     | Sprint (2)                        | move     | +3 move, straight lines only                                                                          |
|            | Trick (4)                         | pre-move | Adjacent opponents must beat your Dribbling or lose their reaction; then you still move               |
|            | Cross (6)                         | act      | From wide in the final third into the box; a teammate within 2 attacks it with a header               |
| Striker    | Run in behind (2)                 | move     | Off-ball, +1 move, ignores marking                                                                    |
|            | Placed (3) / Power (5) / Chip (8) | act      | Shot variants trading zone size vs. save chance; Chip punishes a keeper off his line                  |
| Midfielder | Press (2)                         | move     | +1 move, ignores marking; a carrier you end next to is _pressured_ (wider kicks, easier to tackle)    |
|            | Through ball (3)                  | act      | Nearest teammate within 3 of the drop runs onto it                                                    |
|            | Set tempo (6)                     | act      | A teammate who hasn't acted goes next                                                                 |
| Defender   | Slide tackle (2)                  | act      | Tackle from 2 cells; miss and you're grounded (half move next turn)                                   |
|            | Man-mark (4)                      | act      | Your marking reaches 2 cells for that opponent; step in when they receive                             |
|            | Tactical foul (6)                 | act      | Carrier frozen next turn (free kick); card risk; in your own box it's a penalty. 2 yellows = sent off |
| Keeper     | Command (3)                       | act      | Teammates within 5 regain reactions and react better until their next turn                            |
|            | Rush out (5)                      | move     | +3 move, ignores marking, tackle bonus                                                                |

Passives: Safe hands (every keeper: claims a loose ball within 3 cells between turns, using the reaction), Distributor (GK 1), Vision (MF 5), Aerial threat (ST 6), Shot-stopper (GK 8), Stopper (DF 8),
Elusive (WG 8), Reader (MF 9), Clinical (ST 10).

## AI tuning

The AI values positions in **expected-threat units** (same scale as a shot's goal chance), and prices holding the
ball by who can reach and tackle you _before your next turn_ (turn-order aware). Tune with:

```bash
TT_VARIANTS='{"base":{},"bolder":{"ai":{"xtLinear":0.12}}}' npx vitest run test/tune.test.ts --silent=false
```

## Releases

**Version.** `package.json` is the single source of the version: `tauri.conf.json` reads it, the game shows it at
the bottom of Settings (with the build's commit), and the `version` script keeps `src-tauri/Cargo.toml` in step.

**Cutting a release.** One command, on an up-to-date `main` with a clean tree:

```bash
npm run release              # 0.1.0 → 0.1.1 (or: npm run release -- minor / major / 1.2.0)
```

It uploads the current art and songs to R2 (`assets:upload`), bumps the version with `npm version` (a commit and a
`v…` tag), and pushes both. The tag starts `.github/workflows/release.yml`, which builds on GitHub's runners and
publishes a GitHub Release once every build succeeded:

| File                                      |                                                                     |
| ----------------------------------------- | ------------------------------------------------------------------- |
| `…_macos-universal.dmg` / `.app.zip`      | Apple silicon + Intel                                               |
| `…_windows-x64-setup.exe`                 | installer (built natively, so NSIS works)                           |
| `…_windows-x64-portable.exe`              | runs without installing (needs WebView2, in Windows 10/11)          |
| `…_linux-x86_64.AppImage` / `…_amd64.deb` | Linux (built on Ubuntu 22.04)                                       |
| `…_web.zip`                               | the browser build, for itch.io                                      |
| `SHA256SUMS.txt`                          | checksums of all of the above                                       |
| `THIRD-PARTY-NOTICES.txt`                 | licenses of the bundled open-source packages, fonts and Rust crates |

Every build also carries `THIRD-PARTY-NOTICES.txt` (shown in Settings → About): the license texts of the bundled
JavaScript packages and fonts, plus, in desktop builds, every Rust crate (made with
[cargo-about](https://github.com/EmbarkStudios/cargo-about) from `src-tauri/about.toml`, which accepts permissive
licenses only). `scripts/notices.mjs` writes it; `npm run desktop:build` adds the crates when cargo-about is installed.

The workflow needs the repository secrets `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID` and `R2_SECRET_ACCESS_KEY` (the same
read-only R2 token as the Cloudflare build). A failed platform leaves the release as a draft; re-run the failed job
from the Actions tab and the rest carries on.

**Local desktop builds.** `npm run desktop:build` builds macOS and Windows from a Mac and writes them to
`releases/<version>/` (git-ignored), with a `SHA256SUMS.txt`:

| File                                 |                                                                                |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| `…_macos-universal.dmg` / `.app.zip` | Apple silicon + Intel                                                          |
| `…_windows-x64-setup.exe`            | installer (per user, no admin rights)                                          |
| `…_windows-x64-portable.exe`         | runs without installing (needs the WebView2 runtime, built into Windows 10/11) |

Add `-- --mac` or `-- --windows` to build one platform. The Windows build is cross-compiled (Tauri's
cargo-xwin route) and needs a one-time setup; the script lists anything missing:

```bash
rustup target add x86_64-apple-darwin x86_64-pc-windows-msvc
cargo install --locked cargo-xwin
brew install llvm lld   # + nsis for the installer (optional)
```

The first Windows build downloads Microsoft's CRT and Windows SDK headers (cargo-xwin), which accepts Microsoft's
license for them.

**Unsigned.** The builds aren't signed or notarised, so the first launch takes an extra step:

- **macOS** (ad-hoc signed): open the app once and dismiss the warning, then go to **System Settings → Privacy &
  Security**, scroll to Security and click **Open Anyway** next to Tackle Tactics, and confirm. From macOS 15 on,
  right-click → Open no longer skips the check. If macOS says the app "is damaged", remove the download quarantine
  instead: `xattr -dr com.apple.quarantine "/Applications/Tackle Tactics.app"`.
- **Windows**: SmartScreen shows "Windows protected your PC": click **More info → Run anyway**.
- **Linux**: make the AppImage executable (`chmod +x Tackle-Tactics_*.AppImage`), or install the `.deb`.

**Web deploy (Cloudflare).** The browser build is a static-assets Worker (`wrangler.jsonc`, serving `dist/`).
Cloudflare Workers Builds deploys it on every push to `main`: build command `npm run build`, deploy command
`npx wrangler deploy`. The art and songs aren't in git, so cloud builds download them from a private R2 bucket:

1. Once, and again whenever the art or music changes: `npx wrangler login`, then `npm run assets:upload`. It packs
   `public/assets` and the songs (converted to `.m4a`, since the build machine runs Linux) into
   `game-assets.tar.gz` and uploads it to the `tackle-tactics-assets` bucket (created on first use).
2. In the R2 dashboard, create an API token with **Object Read** on that bucket.
3. In the Worker's build settings, add the build variables `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID` and
   `R2_SECRET_ACCESS_KEY` (the last two as secrets).

When the art is missing and those are set, `scripts/ensure-assets.sh` runs `scripts/fetch-assets.mjs` before the build.

**Browser build.** `npm run web:build` writes `releases/<version>/Tackle-Tactics_<version>_web.zip` with `index.html`
at the top. Upload it to itch.io as an HTML5 game ("This file will be played in the browser"), with a 1600×900
viewport and the fullscreen button on. The build:

- uses relative paths (`base: './'` in `vite.config.ts`), so it runs from whatever folder a host puts it in;
- packs the ~1,400 player sprite strips into one file, `assets/cast.pack` (`scripts/cast-pack-plugin.ts`, read by
  `src/ui/castPack.ts`), which keeps the zip at ~80 files (itch.io allows 1,000);
- saves to the browser's IndexedDB, per browser and site: players can export a backup in Settings → Gameplay.

It needs a desktop browser with a mouse and keyboard. To try the zip locally, unzip it into a folder and serve it,
e.g. `npx serve <folder>`.
